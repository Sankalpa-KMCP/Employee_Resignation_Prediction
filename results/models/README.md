# Model Result Artifacts

Each subfolder stores evidence produced by one headline model. The artifact layouts differ because the models were developed at different times and use different tuning/training protocols.

During the architecture refactor these historical layouts were deliberately preserved rather than renamed en masse. This avoids breaking saved notebook references and keeps prior experiment evidence traceable.

For the group comparison, prefer the headline OOF prediction and summary-metric artifacts identified by each model notebook. After all six final workflows are frozen, these folders can be normalized in a separate controlled cleanup if desired.
