# Historical EBM notebook

`09_m5_ebm_historical.ipynb` preserves the superseded EBM workflow and its saved
outputs. The notebook bytes are retained unchanged as experiment history.

This is an archival reference, not a runnable workflow. Its original code trains
without an activation flag and writes to fixed historical result paths. Do not
run its cells or include it in an active notebook run-all procedure.

Use the [active member 5 notebook](../../../notebooks/team_contributions/models/member_5_ebm/09_m5_ebm.ipynb)
for saved review. Explicitly enabled repeats in the active workflow write to fresh
run directories. The earlier pre-merge archive remains a separate historical
snapshot under `docs/archive/pre_main_merge/`.
